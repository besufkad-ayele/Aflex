# Page Spec — About Us
Route: `/about`

## Purpose
Establish institutional legitimacy (federal mandate, history), values, and leadership — the credibility page a minister or ambassador reads before deciding to attend.

## Section-by-Section Layout

1. **Page header** (component 3.6): breadcrumb "Home / About Us", H1 "About AFLEX", 1-line dek.
2. **Message from the Chief of Academy** — 2-column: portrait of Zadig Abreha left (currently missing photography — request from AFLEX), Fraunces italic pull-quote style message right, name + title in Plex Mono beneath. Reuse the existing message copy, lightly edited for a "letter" register rather than a marketing blurb.
3. **Our Story** — reestablishment narrative: reestablished June 2021 by the Council of Ministers, FDRE; formerly the Meles Zenawi Leadership Academy. Present as a short timeline (2 points: prior identity → reestablishment) using the Plex Mono date-stamp treatment — this is a genuine sequence, so numbered/dated markers are appropriate here (unlike decorative use elsewhere).
4. **Vision & Mission** — 2 side-by-side cards, Fraunces H3 "Vision"/"Mission", body copy as provided.
5. **Values** — icon grid, 6 items (Civility, Optimity, Magnanimity, Integrity, Novelty, Glocality), custom single-weight icon each (see design system §4), label + no elaboration needed (single words are the content).
6. **Pillars** — icon grid, 3 items (Innovate, Integrate, Impact), icon + label + 1-sentence description each, using existing copy.
7. **Board Members** — grid of 7 (Chairperson H.E Tagese Chafo + 6 members). **Gap: no photography exists** — until commissioned, use a placeholder pattern (initials monogram in `ink-900`/`parchment-50`, not a generic silhouette icon) rather than leaving blank.
8. **Senior Executive Team** — grid of 3 (Zadig Abreha, Mrs. Mesert Desta, Wondeye Legesse PhD), same photography treatment as board.
9. **Campus** — short section linking to physical facility description + photography, with a link through to Contact for visit inquiries.
10. **Footer.**

## Components Used
Page header, 2-column bio block, timeline/dated list, value cards, icon grid, portrait grid (with monogram placeholder state), Footer.

## Assets Needed
- Portrait of Chief of Academy (Zadig Abreha) — gap.
- 7 board member portraits — gap, or approved monogram placeholder fallback.
- 3 executive team portraits — gap, or monogram fallback.
- 9 custom icons (6 values + 3 pillars) — commission as single set, see design system §4.
- Campus exterior/interior photography (can reuse Home §6 assets).

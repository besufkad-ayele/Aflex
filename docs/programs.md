# Page Spec — Programs
Route: `/programs`, program detail anchors or sub-routes `/programs/[slug]`

## Purpose
The canonical, detailed source of truth for what AFLEX offers and how to apply — currently the weakest page functionally (verbatim duplicate of About Us copy, "Read More" links go nowhere, zero application mechanism).

## Section-by-Section Layout

1. **Page header**: breadcrumb "Home / Programs", H1 "Programs", dek referencing the 3 pillars (increased access, quality research, consulting/change acceleration).
2. **Program pillars intro** — brief restatement of the 3 supporting pillars as a compact 3-column strip (not full icon cards again — lighter treatment than About's Pillars section to avoid duplication).
3. **Training programs** — 3 full Program detail blocks, each expandable/anchored:
   - **Leadership Development Training** — 3–10 days, short-term, on-demand/bespoke. Fields: audience, format, sample modules (gap — request from AFLEX), CTA "Inquire About This Program" → opens contact/application form (component 3.5) pre-filled with program name.
   - **Project WILD** (Women Integrated Leadership Development Project) — 12–18 months, hybrid, long-term. Needs eligibility criteria and cohort timeline — **currently entirely absent from source content, flag as content gap.** CTA "Apply for Project WILD."
   - **PSLE** (Public Service Leadership Excellence Training) — duration TBD, hybrid, long-term, modular senior executive format. CTA "Inquire About PSLE."
   - Each block uses the Program card pattern expanded to full detail: Plex Mono duration/modality tags, Fraunces H3, full description, and (once available) a short "What You'll Gain" bullet list.
4. **Research & Policy Advisory** — full section (not a teaser):
   - Intro paragraph (as provided).
   - Thematic areas: 8-item tag/list grid (Pan Africanism, Horn/African Countries Political Economy Study, Ethiopian Modern State Leadership and Governance, Nation Building, Intellectualism, Public Diplomacy & International Relations, Leadership Personalities, Institutional Leadership).
   - Featured research: "Pan-Africanism Now" — title, commissioning note, downloadable-document row component if a PDF exists, else "Read Summary" expand.
5. **CTA banner** — closing section: "Not sure which program fits? Talk to our team" → Contact.
6. **Footer.**

## Components Used
Page header, pillar strip, Program detail block (expanded card), tag/badge grid, downloadable-document row, application form (modal or inline drawer, pre-filled program field), CTA banner, Footer.

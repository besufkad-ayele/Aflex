## PART II: Campus Locator & Wayfinding Strategy (AR vs. Interactive 3D / 2D / GIS)

> [!IMPORTANT]
> **Special Focus: How should we implement the Campus Locator experience?**  
> Because the Sululta campus spans extensive acreage with multiple executive buildings, residences, and sports facilities, please review the 4 technical options below and specify your institutional preference.

### 2.1 Technical Approaches for Campus Locator

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                             CAMPUS LOCATOR OPTIONS                               │
├───────────────────────┬──────────────────────────┬───────────────────────────────┤
│ OPTION A:             │ OPTION B:                │ OPTION C:                     │
│ Interactive 2D Vector │ 360° Virtual Tour        │ Augmented Reality (AR)        │
│ Masterplan & GIS      │ & Photosphere Walk       │ WebAR Wayfinding              │
│ (Fast, Universal)     │ (Immersive Desktop/Mobile)│ (On-Campus Mobile Innovation) │
├───────────────────────┼──────────────────────────┼───────────────────────────────┤
│ • Styled SVG map      │ • Matterport / Kuula 360°│ • Smartphone camera view      │
│ • GPS walking routes  │ • Clickable panos of     │ • Live floating 3D arrows     │
│ • Filter by category  │   Auditorium, Lodging    │ • QR code pillars on campus   │
│ • Zero load lag       │ • "Street-view" mode     │ • High "Wow" factor           │
└───────────────────────┴──────────────────────────┴───────────────────────────────┤
```

#### Detailed Comparison Matrix:

| Feature Criteria | Option A: Interactive Vector / GIS Map | Option B: 360° Photosphere Virtual Tour | Option C: Augmented Reality (WebAR) | Option D: Hybrid Tier (Vector + 360° + AR) |
| :--- | :--- | :--- | :--- | :--- |
| **User Experience** | Interactive clickable architectural blueprint with filtering & distance guide. | 360-degree panoramic walkthrough of rooms, villas, and halls. | On-site delegates point mobile camera to see directional 3D markers and building info. | 2D/3D Masterplan online + WebAR experience when scanning on-campus QR signposts. |
| **Target Audience** | General public, new applicants, and drivers navigating to Sululta. | International delegates & VIPs exploring the campus remotely from abroad. | On-campus trainees, conference attendees, and visiting dignitaries. | Universal (covers remote applicants + on-site attendees). |
| **Device Compatibility** | 100% of all devices (Mobile, Desktop, Slow 3G/4G connections). | All modern web browsers (WebGL enabled). | Requires modern iOS/Android smartphones with camera & gyroscope permission. | All devices supported with fallback. |
| **Required Client Assets** | 2D CAD site plan, building footprints, GPS coordinates. | 360° panoramic camera photography (Ricoh Theta, Insta360, or Matterport scan). | Precise GPS coordinates of campus gates, 3D waypoint models, on-site QR codes. | 2D Masterplan CAD + 360° Panoramas + GPS coordinates. |
| **Implementation Complexity** | Moderate (Fastest delivery). | High (Requires dedicated 360° photo capture session). | Advanced (Requires camera permissions & GPS sensor calibration). | Phased rollout (Phase 1: 2D/3D; Phase 2: WebAR). |
